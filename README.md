# 📊 Social Media Engagement Analytics Using Python

## 📌 Analysis Overview

This analysis explores **social media engagement data using Python** to understand content performance, user behavior, engagement patterns, sentiment, and audience trends.

The work covers the complete data analytics workflow, including **data cleaning, exploratory data analysis (EDA), data wrangling, feature engineering, statistical analysis, and data visualization**.

Static and interactive visualizations were created using **Matplotlib, Seaborn, and Plotly** to identify meaningful patterns and communicate insights effectively.

---

## 🎯 Objectives

The main objectives of this analysis are to:

- Clean and prepare social media engagement data for analysis.
- Explore user, content, and engagement characteristics.
- Identify the best-performing post types and content categories.
- Analyze engagement performance across countries.
- Understand how age relates to engagement.
- Compare verified and non-verified account performance.
- Identify posting-time and device-related behavioral patterns.
- Analyze how sentiment relates to engagement.
- Create static and interactive visualizations to communicate findings.

## 🧹 Data Cleaning

The dataset was cleaned and prepared before performing further analysis.

### Missing Values

Missing values were identified and handled according to the characteristics of each variable.

- Missing `age` values were filled using the **median**.
- Missing `gender` values were labeled as **Unknown**.
- Missing values in `likes`, `comments`, and `shares` were filled using their respective **medians**.
- Missing `sentiment` values were filled using the **mode**.

### Duplicate Records

The dataset was checked for duplicate records.

**No duplicate rows were identified**, so no records were removed.

### Data Type Validation

Data types were reviewed and corrected where necessary.

- `posted_at` was converted to datetime.
- `age`, `likes`, `comments`, and `shares` were converted to integer values.
- `is_verified` was retained as Boolean.
- `engagement_rate` was retained as a numerical float variable.

### Category Standardization

Categorical fields were reviewed and standardized to ensure consistent formatting.

The following columns were standardized:

- Gender
- Post Type
- Post Category
- Device Type
- Sentiment

Country abbreviations such as **USA, UAE, and UK** were preserved.

---

## ⚙️ Feature Engineering

New variables were created to support deeper analysis.

### Hashtag Count

A new `hashtag_count` field was created by extracting the number of hashtags associated with each post.

### Engagement Score

A combined engagement score was calculated as:

**Engagement Score = Likes + Comments + Shares**

This represents the total direct interactions generated by each post.

### Log-Transformed Metrics

Log-transformed versions of the following variables were also created:

- Likes
- Comments
- Shares

These transformations can be useful when analyzing variables with wide numerical ranges.

### Time-Based Features

Posting hour and time-of-day information were extracted from `posted_at` to examine the relationship between posting time and impressions.

# 💡 Key Insights

## 1. Content Performance

### 🎥 Post Type Performance

**Video** emerged as the strongest overall post type.

- Average Engagement Score: **12,664.58**
- Average Engagement Rate: **1.12**

Image and Text posts followed closely in average engagement score.

**Reels** recorded the lowest:

- Average Engagement Score: **12,524.01**
- Average Engagement Rate: **0.78**

This indicates that Video content generated the strongest overall performance among the analyzed post types.

---

### 🎵 Content Category Performance

Performance differed depending on the engagement metric considered.

**Music** generated the highest average engagement score:

- Average Engagement Score: **12,788.54**

However, **Food** achieved:

- Average Engagement Rate: **1.36**
- Average Likes: **10,225.50**

Therefore, **Music led in overall interactions, while Food performed strongest based on engagement rate and average likes**.

---

### 🌍 Country Performance

**Brazil** recorded the highest average engagement rate at **1.54**.

The top five countries were:

| Country | Average Engagement Rate |
|---|---:|
| Brazil | 1.54 |
| Australia | 1.32 |
| France | 1.15 |
| UAE | 1.11 |
| Canada | 0.92 |

Brazil therefore showed the strongest average engagement rate among the countries analyzed.

---

## 2. User Trends

### 👥 Age and Engagement

The **46–55 age group** recorded the highest average engagement rate:

- 46–55: **1.21**
- 18–25: **1.04**
- 36–45: **0.96**
- 56+: **0.90**
- Under 18: **0.86**
- 26–35: **0.81**

The results show differences in average engagement across age groups, with users aged **46–55 recording the strongest engagement rate**.

---

### ✅ Verified vs Non-Verified Accounts

Verified accounts achieved:

- Average Engagement Rate: **1.05**
- Average Impressions: **50,747.34**

Non-verified accounts achieved:

- Average Engagement Rate: **0.95**
- Average Impressions: **49,935.29**
- Average Likes: **10,137.19**
- Average Engagement Score: **12,644.30**

Verified accounts therefore had a slightly higher engagement rate and average impressions.

However, non-verified accounts generated more average likes and a higher overall engagement score.

This suggests that **verification status does not consistently result in better performance across every engagement metric**.

---

## 3. Behavioral Insights

### ⏰ Posting Time

The highest observed average impression count occurred at **12:00 AM**, with approximately:

**50,013.73 average impressions**

This suggests that posting time may influence content visibility and can be further explored when developing posting strategies.

---

### 📱 Device Type and Watch Time

**Mobile** users recorded the highest average watch time.

| Device | Average Watch Time (sec) |
|---|---:|
| Mobile | 4,087.83 |
| Tablet | 3,979.74 |
| Desktop | 3,974.79 |

Mobile users therefore demonstrated the strongest viewing-duration performance, although the differences between device types were relatively small.

---

## 4. Sentiment Analysis

### 💬 Sentiment Performance

An interesting finding was that **Negative sentiment posts generated the strongest overall engagement performance**.

| Sentiment | Posts | Avg. Engagement Score | Avg. Engagement Rate |
|---|---:|---:|---:|
| Negative | 960 | 12,731.48 | 1.04 |
| Positive | 2,513 | 12,665.78 | 0.92 |
| Neutral | 1,527 | 12,448.15 | 0.99 |

Although Positive posts were the most common, they did not achieve the highest average engagement.

Negative posts recorded both the **highest average engagement score and highest average engagement rate**.

---

### Negative vs Neutral Sentiment

Negative posts generated higher average:

- Likes
- Shares
- Impressions
- Watch Time
- Engagement Rate

Neutral posts generated slightly more average comments:

- Neutral: **1,528.40**
- Negative: **1,516.09**

This suggests that **Negative posts generated stronger overall engagement, while Neutral posts encouraged slightly more commenting activity**.

---

## 📌 Overall Conclusion

This analysis demonstrates that social media performance is influenced by multiple factors, including **content type, content category, audience characteristics, posting time, device usage, geographic location, and sentiment**.

Key observations include:

- **Video** was the strongest overall post type.
- **Music** achieved the highest average engagement score among content categories.
- **Food** achieved the highest average engagement rate among content categories.
- **Brazil** recorded the highest average engagement rate among the analyzed countries.
- The **46–55 age group** recorded the highest average engagement rate.
- Verified accounts had higher average engagement rates and impressions, while non-verified accounts generated higher overall engagement scores.
- **Mobile** users recorded the highest average watch time.
- **Negative sentiment posts** unexpectedly generated the highest average engagement score and engagement rate.

Overall, the findings demonstrate the importance of analyzing **multiple engagement metrics instead of relying on a single performance measure** when evaluating social media content.
